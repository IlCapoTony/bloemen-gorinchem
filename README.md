# Bloemen Gorinchem

Een lokale online gids voor bloemisten in Gorinchem. De site helpt inwoners en bezoekers van Gorinchem bij het vinden van de beste bloemist voor hun wensen — van bruidswerk tot rouwboeketten, bezorging en bloemenabonnementen.

## Tech stack

- [Astro](https://astro.build/) — statische sitegenerator
- Gehost via GitHub Pages

## Lokaal ontwikkelen

```bash
npm install
npm run dev
```

De site draait op `localhost:4321`.

## Bouwen

```bash
npm run build
```

De productie-build verschijnt in `dist/`.
